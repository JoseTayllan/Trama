# Guias de execução e distribuição

Esta pasta concentra os procedimentos operacionais do Trama, separados dos capítulos de estudo do código e dos relatórios históricos de revisão.

- [Desenvolver e executar pelo WSL](wsl/README.md): entrar no Ubuntu, abrir o VS Code, executar e testar; diferença entre fontes, espelho e bancos.
- [Publicar e compartilhar para Windows](windows/README.md): gerar o exe atualizado, preparar o ZIP e enviar ao colega.
- [PDF para quem vai testar](../../output/pdf/Trama_Guia_de_Execucao_Windows.pdf): extrair, executar, criar atalho e conferir o salvamento.

Os relatórios 027 e 028 continuam em `docs/reviews/` como evidências históricas. O guia WSL foi movido da central de estudos para esta pasta; os links foram atualizados.
